# bob-quality-action-hub-lab

In this hands-on lab, you will use IBM Bob to understand a set of manufacturing application requirements, create an implementation plan, and build the first version of a manufacturing quality dashboard.

The lab follows a simple development workflow:

Ask mode: Understand what needs to be built.
Plan mode: Decide how to build it.
Agent mode: Build and validate the first version.

Hands-on instructions here https://github.com/heena179/bob-quality-action-hub-lab/blob/main/IBM_Bob_Manufacturing_Hands_On_Lab.md
